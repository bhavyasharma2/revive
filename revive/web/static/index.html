Revive

Repairs ML notebooks that broke when their libraries changed, then proves the fix: every cell is re-run and checked against the output its author saved.

Notebook

Pick a broken notebook and press Repair notebook.

Repair log

    Each repair runs the notebook in its own Python environment. A large Nemotron model reads the error, the library versions and the changelog Tavily finds, and writes a patch. A notebook only counts as verified when every cell's fresh output matches the reference within a numeric tolerance: the outputs its author saved or, for a notebook saved without them, the outputs of the untouched original in its rebuilt environment. A fix that runs but changes the numbers is sent back.
